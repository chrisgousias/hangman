HANGMAN GAME


This is a simple hangman game for TheOdinProject Ruby course.

The game opens up a dictionary of 10.000 english words and it randomly select between 5 and 12 characters long for the secret word. The player starts guessing letters and if it exists in the word, it appears. The player has 6 failed guesses to guess the word.

The code of the game does the following:
- prompts the user to enter a letter
- displays the secret word by _ _ _ _ _ _ x _ x _ where 'x' is a letter
- displays the letters that the user has entered and don't exists in the word
